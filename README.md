# Java Fundamentals

This repository contains basic Java programs created as part of the **BridgeLabz Training**.  
These programs cover fundamental Java concepts such as variables, operators, input/output, and basic mathematical operations.

## 📂 Files in this Repository

| File Name            | Description |
|----------------------|-------------|
| `add.java`           | Program to perform addition of numbers. |
| `area.java`          | Program to calculate the area of given shapes. |
| `celcius.java`       | Program to convert temperature from Fahrenheit to Celsius. |
| `printstatement.java`| Demonstrates the use of `System.out.println()` and printing text in Java. |
| `volume.java`        | Program to calculate the volume of a 3D object. |

## 🛠 How to Run the Programs
1. Make sure you have **Java JDK** installed.
2. Open a terminal/command prompt in the directory containing the file.
3. Compile the Java file:
   ```bash
   javac filename.java
